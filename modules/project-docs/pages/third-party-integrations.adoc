Linq2Couchbase creates a lightweight ORM/ODM for querying Couchbase buckets using LINQ as the lingua-franca between your application and Couchbase Server using Couchbase's {sqlpp} for JSON documents.
It also provides a write API for performing CRUD operations on JSON documents.
